# insurance_premium_predictor

🚀 Insurance Premium Predictor

A machine learning-powered application that predicts insurance premium categories based on user demographics and lifestyle factors.

Tech Stack:

Python

Random Forest Classifier

FastAPI

Scikit-learn

Input Features:

Age

Height

Weight

Smoker Status

City

Occupation

Output:

Low Premium

Medium Premium

High Premium

The model helps estimate premium categories by analyzing health, demographic, and occupational risk factors.
